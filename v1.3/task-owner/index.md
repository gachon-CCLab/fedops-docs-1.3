# Task Owner

새 Federated Task를 만들거나 기존 로컬 모델을 연결한 뒤, Registry에 공개하는 방법을 안내합니다.

| 시작 상황 | 가이드 |
| --- | --- |
| FedOps Web에서 새 Task를 생성한다 | [Create a New Task]({{ '/v1.3/task-owner/create-task/' | relative_url }}) |
| 기존 Python/PyTorch 프로젝트를 연결한다 | [Import a Local Model]({{ '/v1.3/task-owner/import-model/' | relative_url }}) · 작성 중 |

처음 사용하는 경우 [Getting Started]({{ '/v1.3/getting-started/' | relative_url }})에서 Agent Studio를 준비합니다.

코드 작성 기준은 [Federated Task Developer Guide]({{ '/v1.3/developer-guide/' | relative_url }}), 게시 후 서버 운영은 [Campaign & Server Management]({{ '/v1.3/campaign/' | relative_url }})를 참고하세요.
